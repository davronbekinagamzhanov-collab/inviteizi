# InviteIZI — правила проекта (единственный источник правды, 19.11.2026)

Читать перед любой работой. Если код и этот файл расходятся — проверь код, исправь файл.
Отчёты владельцу (Давронбек, начинающий) — по-русски, простыми словами.

## Продукт
Telegram-бот + Mini App, продают онлайн-пригласительные на узбекские торжества (никоҳ, фотиҳа/қиз базми,
суннат, наҳорги ош, бешик, юбилей/туғилган кун, худойи). Рынок — Сайрам (Шымкент), узбекская община.
Клиент: выбирает дизайн → заполняет данные (1–3 тадбира, у каждого дата/время/место/карта) → платит
Kaspi → получает ссылку `inviteizi.vercel.app/{slug}`. Один движок: заказ = строка в БД, `/{slug}`
рендерит шаблон с данными. Никаких «сайтов на клиента».

## Роли (права проверяются только на сервере по Telegram initData)
- **Клиент** — заказывает, платит, видит свои заказы и ответы гостей (RSVP).
- **Владелец** — `OWNER_TELEGRAM_ID` / `ADMIN_IDS`; Mini App с кнопкой «InviteIZI · Админ»
  (`bot/flow/menu-button.ts`): ✅/❌ оплат, бесплатное создание, заказ для клиента, акции и рассылка,
  промокоды (создаёт только `OWNER_TELEGRAM_ID`), партнёры, выплаты, менеджеры, оптовики, статистика.
- **Менеджер** — кнопка «InviteIZI · Панель», только свои заказы, фиксированная ставка.
- **Партнёр** — становится партнёром только по ссылке `join_…` от владельца (не по @username);
  своя ссылка `p_…`, процент с реально оплаченной суммы, начисление ровно 1 раз.
- **Оптовик** — назначает владелец; оптовая скидка, без акций и промокодов, без начислений партнёрам.
- Любой запрос админки/панели от чужой роли → 403 (тест `bot/roles.scenarios.test.ts`).

## Цены (с 17.11.2026, `templates/registry.ts` → `PRICES` — единственный источник)
- Оддий (simple) **2 990 ₸**, Варақланадиган (scroll) **4 990 ₸**, Анимацияли (animated, вкл. VIP) **7 990 ₸**.
- Скидки округляются вниз до числа на …90 (`lib/pricing-math.ts`); 100 % = 0 ₸ — ссылка сразу, без оплаты.
- Неоплаченные заказы получают актуальную цену при показе; `receipt_sent` и оплаченные — не меняются.
- Старые цены 5 000 / 6 000 / 8 000 ₸ нигде в интерфейсе появляться не должны.
- Музыка входит в цену. Ручная правка дизайна — 2 000 ₸ лично через владельца («Боғланиш»).

## Оплата
- Основной путь: экран Kaspi (номер и сумма крупно, «📋» копирование) → «✅ Тўладим» → имя из Kaspi
  (2–40 символов, ≤ 3 раз в час на заказ) → заказ `receipt_sent` → владелец сверяет с Kaspi → ✅ / ❌
  («Тўлов келмади» → клиент снова видит «✅ Тўладим»).
- Чек — по желанию («📎 Чек юбориш (ихтиёрий)»), хранится только в Telegram.
- Подтверждают только админы. Статусы: `draft → preview → awaiting_payment → receipt_sent → active → archived` (+ `rejected`).

## Скидки (не складываются — берётся одна, бо́льшая; модуль `bot/pricing.ts`)
- **Акции** (админка «🎉 Акции», одна одновременно, рассылка клиентам ≤ раз в 3 дня, ≤ 2 сообщения на акцию).
  Не действуют для партнёров, менеджеров, оптовиков, админов; клиентам по ссылке партнёра — по переключателю акции.
- **Промокоды** — флаг `MARKETING_PROMOS_ENABLED`; ❌ оплаты возвращает использование.
- **Оптовая скидка** — только оптовикам.

## Файлы и данные
- База — Supabase Postgres (`lib/db.ts`, `bot/repo-pg.ts`). Миграции/SQL — **только файлами**
  (`supabase/migrations/`, `supabase/release/`), применяет владелец.
- **Supabase Storage не использовать**: с 16.11.2026 отвечает 402 (кончился бесплатный трафик).
  Скрипты, которые туда пишут, отключены с понятным сообщением.
- Фото клиента и своя песня — Vercel Blob (`lib/storage.ts`, `BLOB_READ_WRITE_TOKEN`). Без токена ничего не падает.
- Музыка библиотеки и демо-мелодии — статика `public/audio/...` (`/audio/originals/*`, `/audio/lib/*`).
  В списках показываем только песни, у которых файл реально есть в `public/` (тест).
- Автоочистка: через 30 дней после последнего тадбира (или `expires_at`) удаляются файлы клиента;
  ссылка показывает заглушку.

## Флаги прода (Vercel env, `lib/marketing/config.ts`, `lib/env.ts`)
- Включены: `MARKETING_UI_ENABLED`, `MARKETING_AUTOMATION_ENABLED` (главный, без него остальные marketing-флаги не работают),
  `MARKETING_PROMOS_ENABLED`, `MARKETING_STATUS_ENABLED` = `true`.
- Выключены по решению владельца: `MARKETING_REFERRALS_ENABLED`, `MARKETING_EDITS_ENABLED`, `KAZAKH_ENABLED`.
- `MINI_APP_ENABLED` — по умолчанию включён. Подробно: `docs/LAUNCH.md`.

## Языки
- Бот и Mini App: узбекский (кириллица) и русский, выбор при первом входе, смена в меню. Казахский — за флагом.
- Приглашение: по умолчанию узбекский (кириллица); можно русский. Тексты — только в `texts/`
  (`uz-cyrl.ts`, `invite-ru.ts`, `bot-uz.ts`, `bot-ru.ts`, `app-uz.ts`, `app-ru.ts`), не в шаблонах.

## Экономия
- Сначала grep/чтение нужных фрагментов, потом правка. Не переписывать работающий код.
- Тесты после правки — изменённых файлов; полный прогон — один раз в конце.
- Браузер — только для изменённых мест. Неудачную команду не повторять больше 2 раз — искать причину.
- Лимит кончается → коммит, пуш, строка в `ПРОГРЕСС.md`, где остановился.
