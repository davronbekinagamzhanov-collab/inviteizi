# Что препятствует полной готовности

Это журнал недостающих данных/доступов, не запрос секретов в чат.

1. В репозитории и приложении нет упомянутого полного `МАСТЕР_ПРОМПТ.md`. Реализованные изменения опираются на `AGENTS.md`, существующий код и переданное дополнение.
2. Нет настроенного доступа к Vercel, Supabase и действующему Telegram API в этом рабочем окружении. Миграция, переменные владельца и разрешения аналитиков не применены в production. Полный тест реальной связки Telegram → Supabase → подтверждение владельцем не выполнен; проверен симулятор и SQL на PGlite.
3. В реестре 21 дизайн, клиентам доступны 9. Остальные включают 11 прямых заглушек и скрытый дизайн. Требование 50 качественных, разных, принятых приглашений не выполнено. Нужны самостоятельная художественная разработка и приёмка оставшихся дизайнов, реальные изображения с правами; простое открытие заглушек не решает задачу.
4. Есть доступные музыкальные файлы, но в Git нет полного подтверждения прав на распространение каталога. Расширение легальной библиотеки не выполнено; случайные скачанные песни не добавлены.
5. Без `OWNER_TELEGRAM_ID` приватная аналитика выключена. Без отдельного секрета трекинга не собираются открытия демо. Значения устанавливаются в окружении сервера и не публикуются в Git.
