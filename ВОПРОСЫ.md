# Что препятствует полной готовности

Уточнение 25.10: цель обновлена до **60 дизайнов всего**, прежнее число 50 ниже — история. В текущем окружении нет отдельной тестовой PostgreSQL, Pixabay API key и подтверждённо лицензированных новых аудиофайлов. Это блокирует только соответствующие внешние проверки/материалы, а не исправления кода и работу над дизайнами без фото. Production-доступ не запрашивается и не используется.

26.10: SQL-контракт и нагрузки 100/1 000 проверяются через изолированную локальную PGlite; это не native PostgreSQL/Supabase. Для двух настоящих фото найден и проверен альтернативный CC0-источник Wikimedia; отсутствие Pixabay key не блокирует эти дизайны. У старых клиентских аудио-URL могут оставаться числовые ID в пути; без разрешения не переносить объекты и не переписывать оплаченные заказы. Новые загрузки исправлены.

Это журнал недостающих данных/доступов, не запрос секретов в чат.

1. В репозитории и приложении нет упомянутого полного `МАСТЕР_ПРОМПТ.md`. Реализованные изменения опираются на `AGENTS.md`, существующий код и переданное дополнение.
2. Нет настроенного доступа к Vercel, Supabase и действующему Telegram API в этом рабочем окружении. Миграция, переменные владельца и разрешения аналитиков не применены в production. Полный тест реальной связки Telegram → Supabase → подтверждение владельцем не выполнен; проверен симулятор и SQL на PGlite.
3. После сохранения второй партии в реестре 21 дизайн, приняты 20; прямых заглушек не осталось, anor-bogi скрыт. Цель **60 готовых всего** ещё не выполнена. Следующие дизайны не создавать до отдельного задания владельца.
4. Есть доступные музыкальные файлы, но в Git нет полного подтверждения прав на распространение каталога. Расширение легальной библиотеки не выполнено; случайные скачанные песни не добавлены.
5. Без `OWNER_TELEGRAM_ID` приватная аналитика выключена. Без отдельного секрета трекинга не собираются открытия демо. Значения устанавливаются в окружении сервера и не публикуются в Git.
