# InviteIZI — состояние на 25.10.2026

## Статус

Подготовлена проверенная часть доработки существующего коммерческого проекта. Полное дополнение мастер-промпта **ещё не выполнено**: 50 качественных дизайнов и расширение музыкальной библиотеки остаются в работе. Код предназначен для отдельной ветки и PR без автоматического объединения.

## Готово

- Аудит существующего GitHub-репозитория и сохранение архитектуры Telegram → существующий Repo → PostgreSQL → персональная страница.
- Персональная НАМУНА ровно на 24 часа; редактирование срок не продлевает; подтверждение оплаты открывает ту же ссылку.
- Мобильные появления на IntersectionObserver вместо отдельных scroll/resize-обработчиков у каждого блока. Уважение reduced motion и удаление постоянных GPU-слоёв лепестков.
- Исправление сборки существующих дизайнов с Lora; стандартный Tailwind PostCSS.
- OG-карточка с обложкой выбранного дизайна без примерных имён и приватного адреса; локальные шрифты.
- Постоянное избранное, добавление/удаление, список, переход к демо и продолжение заказа.
- `/dashboard`, совместимые `/stats` и `/orders`, персональный `/customers` только владельцу.
- Периоды Asia/Almaty, реальные финансовые показатели, аналитика дизайнов, музыки, повторных покупателей, PNG-графики всех семи типов.
- Идемпотентные события, финансовые события в транзакции заказа; отдельная SQL-миграция с RLS и запретом чтения публичным ролям.
- Непрозрачные маркеры демо, без открытого Telegram ID в URL; серверные/preview-запросы сами открытия не создают.
- Нет новых рефералов, промокодов или сторонних аналитических сервисов.

## Проверено

- `npm test`: **223 passed, 30 skipped**. Пропущены существующие тесты удалённой PostgreSQL без настроенного подключения.
- SQL-миграция на локальном PGlite: схема, транзакционные финансовые события, уникальность избранного, права `anon`/`authenticated`.
- Симулятор владельца: чек → подтверждение/отказ, повторное подтверждение, старые кнопки, корректное обновление выручки.
- Генерация настоящих PNG: пустые данные, длинные названия, узбекская кириллица, отсутствие сетевых запросов для fallback-шрифтов/emoji.
- `npm run lint` и `npx tsc --noEmit`: успешно.
- `npm run build`: успешно, 76 страниц; остаётся некритическое предупреждение Next.js об автоматическом fallback Libertinus Serif.
- Production в Chrome: **27/27** — 9 принятых дизайнов × 360/375/430 px, без ошибок браузера, горизонтальной прокрутки и видимых застрявших блоков.
- Dev в Chrome: **9/9** — длинные имена и три события на 375 px. Reduced motion проверен.
- Четыре существующих публичных demo MP3: HTTP 200, `audio/mpeg`. Это проверка доступности, не лицензий.
