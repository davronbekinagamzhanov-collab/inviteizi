# «Натуральный» стиль приглашений

Как делать новые дизайны в духе пилотов Муҳр, Ипак, Боғ и Тонгги дастурхон (02.11.2026).

## Суть
Настоящие фото в рамках, рукописные слова-акценты, много воздуха, один цвет на бумаге. Приглашение похоже на хорошую
бумажную открытку и журнал, а не на сайт.

## Правила
1. **Палитра: бумага и один цвет.** Бумага тёплая или холодная (`--n-paper`), текст (`--n-ink`), один акцент (`--n-accent`).
   Никаких золотых градиентов, блеска и свечения.
2. **Шрифты** (`templates/themes/natural/fonts.ts`): Cormorant Garamond — заголовки и крупные цифры (300 — тонкие),
   Lora — текст, Great Vibes — рукописные слова. В Great Vibes нет қ ғ ҳ: компонент `Script` сам берёт Bad Script.
   Рукописные слова — короткие (`t.natural.*`), тест следит, чтобы в них не было қ ғ ҳ.
3. **Фото только настоящие, без лиц.** Рамки из `kit.tsx`: `arch`, `round`, `circle`, `torn` / `tornTop` (рваный край).
   В одном дизайне — одна-две формы рамки, не все сразу. Фото клиента (`data.photos`) встают первыми, стоковые — запасными
   (`shots()`), при сильно другой пропорции — `contain` на размытом фоне.
4. **Источники:** Unsplash — только hotlink `images.unsplash.com` + download-эндпоинт при выборе (`scripts/unsplash.mjs`,
   кэш запросов, 50 в час). Pixabay — видео (≤2 МБ, без звука) и запасные фото, локально в `public/art/natural`.
   Подпись «Сурат: Имя / Unsplash» с utm — автоматически над плашкой InviteIZI (`credits` у `InvitationShell`).
5. **Раскладка не по центру.** Текст смещён влево или вправо, есть вертикальные заголовки (`SideTitle`), крупное время,
   фото со смещением и наложением. Одинаковых карточек подряд нет.
6. **Рисованное от руки — только SVG-линии:** кружок в календаре (`HandCalendar`), стрелки-завитки (`Squiggle`).
   Рисуются при появлении на экране. Симметричных орнаментов кодом не рисуем.
7. **Зелень** — только прозрачные акварельные PNG/WebP (`garland`, `sprig`, `eucalyptus`), одна-две на страницу.
8. **Движение:** открытие у Анимацияли (конверт, видео с ▶), дальше только мягкое появление. У Варақланадиган экрана
   открытия нет — первый экран сразу содержимое. Если блок может «проскочить» при быстром листании — без `Reveal`.
9. **Ответы гостей** в цветах дизайна: `rsvpLook` (бумага, линия, акцент, шрифт, радиус).
10. **Каждый дизайн — свой порядок блоков и свой «главный приём»** (конверт, видео, круг с зеленью, плов с рваным краем).
    Перекраска чужой раскладки — не новый дизайн.

## Проверка
- `node scripts/shoot-natural.mjs <id> --widths=430,360 --full --out=art-raw/shots` — кадры, ошибки, переполнение.
- `node scripts/check-template.mjs <id> --base=http://localhost:3100` — общая проверка (мелкий текст в футере InviteIZI общий для всех).
- `BASE=… node scripts/make-covers.mjs <id>` и `node scripts/make-natural-og.mjs <id>` — обложки и превью ссылки без текста.
- Новый id — строка в `templates/registry.ts`, обложки, и SQL строки каталога (по «да» владельца) до выкладки.
