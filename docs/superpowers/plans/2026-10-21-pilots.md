# 5 пилотных пригласительных InviteIZI — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пять пилотных пригласительных на localhost с примерными данными, на уровне эталонов или лучше — витрина качества для остальных 55 дизайнов.

**Architecture:** Один движок: `app/demo/[template]` рендерит дизайн из `templates/registry.ts` с данными из `lib/pilot-samples.ts`. Общая механика (данные, тексты, музыка WebAudio, открытие, Reveal, карта 2GIS, НАМУНА) — в `templates/blocks/` и `texts/uz-cyrl.ts`. Каждый пилот — своя папка `templates/themes/<id>/` со своим открытием, раскладкой, декором, шрифтами и мелодией.

**Tech Stack:** Next.js 16.4 (App Router), React 19, Tailwind 4, motion 14, next/font/google, WebAudio, playwright-core + Chrome для проверки, sharp для картин, Pollinations для картин.

**Spec:** задание владельца «5 пилотных пригласительных InviteIZI» (`../ПИЛОТЫ_ПРОМПТ.md`), `CLAUDE.md`, `План проекта/10_ЭТАЛОНЫ_И_60_ДИЗАЙНОВ.md`. Общие правила для исполнителя: `docs/superpowers/plans/pilot-common.md`.

## Global Constraints

- Только телефон: 360–430px; на компьютере та же страница по центру шириной 430px. Нет горизонтальной прокрутки.
- Всё, что видят клиент и гости, — узбекский, КИРИЛЛИЦА, грамотно. Все тексты — в `texts/uz-cyrl.ts`.
- Шрифты с поддержкой ў қ ғ ҳ (cyrillic-ext). У каждого пилота своя пара шрифтов.
- Золото — градиентом с бликом (#B8892F → #F3D58A → #A87A28), не плоским жёлтым.
- Музыка: своя мелодия WebAudio; только после нажатия; кнопка ▶/⏸ в углу.
- «Харитада очиш» открывает 2GIS по координатам из данных.
- /demo/<id>/namuna: водяной знак, без музыки.
- Картины: Pollinations, 3 варианта с разными seed, выбирается лучший; `public/art/<id>.webp` ≤ 300 КБ; промпты в `art-prompts.md`.
- Первый экран ≤ 2 с, анимации 60 fps, картинки lazy (кроме первой).
- Блоки при листании видны сразу, появление ≤ 0,4 с, при быстром листании нет пустого экрана.
- Каждый пилот проверен в 375×812 и 360×640: скриншоты в `pilots-screens/<id>/`, нет ошибок консоли, проходит 8 пунктов «капризного клиента».
- Не трогать Supabase, Vercel и бота.

## Review Focus

1. Шрифт без глифа қ/ғ/ҳ → буква выпадает в системный шрифт. Ожидание: все буквы в одном шрифте (проверка глазами на скриншоте).
2. Быстрое листание сразу после открытия → пустой экран. Ожидание: `blankScreens` пуст (check-pilot).
3. iPhone в беззвучном режиме / вкладка ушла в фон → музыка молчит/играет в фоне. Ожидание: `navigator.audioSession = playback`, пауза при уходе со вкладки (useInvitation, synth.ts).
4. Экран 360×640 (маленький Android) → Пилот 2 не помещается, у анимированных — кнопка открытия ниже края. Ожидание: Пилот 2 `fitsOneScreen: true`, у остальных заставка целиком видна.
5. Открытие на компьютере (ширина 1440) → декор и кнопка музыки вне колонки 430px. Ожидание: всё внутри колонки.
