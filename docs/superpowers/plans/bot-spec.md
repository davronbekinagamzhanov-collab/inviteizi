- `bot/flow/*.ts` — вся логика: `handle(deps, update)`; `deps = { repo: Repo; tg: Tg; env: BotEnv; now: () => Date }`. - `app/api/cron/route.ts` — POST с `x-cron-secret`: напоминание админу (чек ждёт > 30 мин, один раз), клиенту (на оплате > 3 ч, один раз), архивирование (expiresAt прошёл → archived).
- `bot/repo-memory.ts` — `Repo` в памяти + `bot/repo.contract.ts` (общий набор тестов поведения Repo; БЭКЕНД прогонит его на pg).
- Тесты: `bot/flow.test.ts` (и при желании по файлам на сценарий) — `FakeTg` записывает исходящие сообщения; сценарии гоняют `handle` с repo-memory.
- Тексты: `texts/bot-uz.ts` и `texts/bot-ru.ts` — одинаковые ключи (тип из uz, ru `satisfies`), тон дружелюбный и простой (пользуются пожилые), короткие сообщения (3–4 строки), с примерами («Масалан: Азиз»).
