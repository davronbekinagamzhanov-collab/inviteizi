# Запуск рекламы: флаги по порядку

Флаги меняются только в Vercel → Settings → Environment Variables (Production), затем **Redeploy**. Значение `true` включает, удаление переменной или любое другое значение — выключает. Перед каждым шагом убедитесь, что миграция `20261115130000_marketing_automation.sql` применена (иначе экран «Промокоды» в админке пишет «ещё не подключены к базе»).

Одна проверка на каждом шаге: свой тестовый заказ с другого Telegram-аккаунта (не админа) → чек → ✅ в админке → ссылка пришла.

| # | Флаг | Что включает | Что проверить после | Как выключить |
|---|---|---|---|---|
| 0 | `WHATSAPP_PHONE` = `77011234567` | Кнопка WhatsApp на странице приглашения из каталога | Открыть `/catalog/invite`: кнопка ведёт на ваш номер | Удалить переменную |
| 1 | `MARKETING_AUTOMATION_ENABLED` = `true` | Главный выключатель: выдача ссылки после ✅ через очередь, `/delivery`. Без него флаги 2–5 не работают | Тестовый заказ → ✅ → ссылка у клиента ровно один раз; `/delivery` — пусто | Удалить → бот выдаёт ссылки как раньше (флаги 2–5 тоже выключатся) |
| 2 | `MARKETING_PROMOS_ENABLED` = `true` | Промокоды: клиент пишет `/promo <номер заказа> <КОД>` | Админка → Промокоды: создать код (5 %, лимит 1) → клиент вводит → сумма со скидкой → чек → ✅ → «использовано 1 из 1». При ❌ — снова «0 из 1» | Удалить; или в админке «Выключить» конкретный код |
| 3 | `REFERRAL_REWARD_KZT` = `1000` | Сколько ₸ получает клиент за друга (по умолчанию 1000) | Задать до флага 4 | Удалить → 1000 |
| 4 | `MARKETING_REFERRALS_ENABLED` = `true` | Клиент после оплаты получает свою ссылку «пригласи друга», `/referrals` | Оплаченный тестовый клиент получил ссылку; друг по ней заказал → ✅ → в админке «Выплаты» у «Покупатель #…» сумма один раз | Удалить (уже начисленное остаётся в «Выплатах») |
| 5 | `MARKETING_STATUS_ENABLED` = `true` | После оплаты — картинка для статуса WhatsApp/Telegram | После ✅ клиенту пришла картинка одна | Удалить |
| 6 | `MARKETING_EDITS_ENABLED` = `true` | Клиент просит правку `/correction` (первая за 24 ч бесплатно, потом 2 000 ₸) | `/correction` от клиента → владельцу пришло сообщение; `/corrections` — список | Удалить |

Партнёрские ссылки (`join_` из админки → «Партнёры» → «Новый партнёр») работают без флагов: начисление партнёру идёт после ✅, один раз на заказ (проверено тестом).

## Если что-то пошло не так

1. Выключить последний включённый флаг и сделать Redeploy — прежнее поведение возвращается, заказы и начисления не теряются.
2. `/delivery` — какие сообщения не дошли; `/delivery_retry <ключ>` — повторить.
3. Ошибочная оплата — `/refund <номер> <причина>` (начисление партнёру обнуляется, деньги переводите сами).
