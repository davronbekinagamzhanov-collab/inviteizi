# Запуск рекламы: флаги по порядку

Флаги меняются только в Vercel → Settings → Environment Variables (Production), затем **Redeploy**. Значение `true` включает, удаление переменной или любое другое значение — выключает. Перед каждым шагом убедитесь, что миграция `20261115130000_marketing_automation.sql` применена (иначе экран «Промокоды» в админке пишет «ещё не подключены к базе»).

Одна проверка на каждом шаге: свой тестовый заказ с другого Telegram-аккаунта (не админа) → чек → ✅ в админке → ссылка пришла.

## Выпуск 17.11.2026: цены, оплата без чека, «Оддий»

2. `npm run db:seed-templates` — новые цены 2 990 / 4 990 / 7 990 в таблице `templates`.
3. Проверить: тестовый заказ → «✅ Тўладим» → имя → вам пришло «№ · сумма · имя · время» → ✅ → ссылка у клиента. ❌ «Тўлов келмади» → клиент снова может нажать «✅ Тўладим».
4. Откат: прежние цены — в `templates/registry.ts` (`PRICES`), чек по-прежнему принимается.

## Файлы клиентов без Supabase Storage (17.11.2026)

С 16.11 Supabase Storage отвечает 402 (кончился бесплатный трафик). Фото клиентов и своя песня теперь хранятся в **Vercel Blob**, чеки — как и раньше только в Telegram (в хранилище не попадают).

Подключить хранилище (один раз, 2–3 клика):
1. Vercel → проект **inviteizi** → вкладка **Storage** → **Create Database** → **Blob**.
2. Название `inviteizi-files`, доступ **Public** (имена файлов — случайные 32–64 символа, без имён клиентов), регион ближе к Казахстану (например, Frankfurt) → **Create**.
3. В окне **Connect to Project**: проект `inviteizi`, окружения **Production** и **Preview**, префикс переменной оставить пустым → **Connect**. Vercel сам добавит переменную `BLOB_READ_WRITE_TOKEN`.
4. **Deployments → … → Redeploy** последнего production-деплоя.

Проверить: в боте отправить фото в анкету и свою песню (mp3) → «✅ Қўшиқ қабул қилинди»; в Mini App «Ўз мусиқам» → процент → «Тайёр».
Пока токена нет, клиент видит «Файлы сейчас временно не сохраняются», бот и приглашения работают (выбор музыки из списка, без фото).

Ограничения: фото — до 600 КБ после сжатия; своя песня — только mp3/m4a, до 12 МБ.

## Акции и оптовики (без флага)

Перед первой акцией примените миграцию `20261117120000_promotions_wholesale.sql` (Supabase → SQL editor). Без неё «Новая акция» отвечает «ещё не подключены к базе», цены не меняются.

1. Админка → «🎉 Акции» → «Новая акция»: название, скидка (100 % = бесплатно), начало и конец, тадбиры и форматы. Одна акция одновременно.
2. Проверить: с аккаунта обычного клиента в каталоге — баннер с таймером и зачёркнутые цены; с аккаунта партнёра — без бейджей; тестовый заказ → на проверке старая цена зачёркнута и «Тежайсиз …»; при 100 % — без чека, ссылка сразу.
3. Выключить: «Остановить» — бейджи исчезают сами, неоплаченные заказы при следующем шаге оплаты получают обычную цену.

### Рассылка об акции (без флага)

Перед первой рассылкой примените миграцию `20261117130000_promotion_broadcast.sql` (после `20261117120000`). Без неё рассылка ничего не отправляет, акции работают.

1. При создании акции оставьте «Разослать клиентам» и «Напомнить «Охирги кун!»» включёнными (по умолчанию).
2. Сразу после создания — предпросмотр (уз/ру, картинка, кнопки) и число получателей → «📣 Отправить». Первая партия уходит сразу, остальное — cron, 25 сообщений в секунду.
3. Проверить: тестовому клиенту пришло одно сообщение; в «Акциях» строка «Рассылка: отправлено … · заблокировали … · ошибки …».
4. Получают: все, кто нажимал /start, кроме админов, менеджеров, партнёров, оптовиков и нажавших «🔕». Клиенты по ссылке партнёра — только если включено в акции. Рассылка не чаще раза в 3 дня, на акцию — не больше 2 сообщений.
5. Остановить: «Остановить» акцию — неотправленные сообщения не уйдут.

### Промокоды у клиента

Кнопки «🎟 Промокод» (бот) и «Есть промокод?» (Mini App) появляются только при `MARKETING_AUTOMATION_ENABLED=true` и `MARKETING_PROMOS_ENABLED=true`. Пока флаги выключены, кнопок нет совсем, а экран «Промокоды» в админке предупреждает, что клиенты не смогут ввести код.

Оптовик: админка → вкладка «Оптовики» (по № заказа) или карточка партнёра → «Назначить оптовиком». Снять — там же.

Партнёрские ссылки (`join_` из админки → «Партнёры» → «Новый партнёр») работают без флагов: начисление партнёру идёт после ✅, один раз на заказ (проверено тестом).

## Если что-то пошло не так

1. Выключить последний включённый флаг и сделать Redeploy — прежнее поведение возвращается, заказы и начисления не теряются.
2. `/delivery` — какие сообщения не дошли; `/delivery_retry <ключ>` — повторить.
3. Ошибочная оплата — `/refund <номер> <причина>` (начисление партнёру обнуляется, деньги переводите сами).
