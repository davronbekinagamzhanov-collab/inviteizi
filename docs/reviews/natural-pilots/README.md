# Натуральные пилоты — ревью (фаза 4)

Скриншоты 430 px: `<id>-430-0-opening` (только у Анимацияли), `-1-first`, `-2-middle`, `-3-end`.
Пилоты: `muhr`, `ipak` (никоҳ, Анимацияли), `bog` (суннат), `tong-dasturxon` (наҳорги ош) — оба Варақланадиган.

## Что нашёл критик и что сделано

| Замечание | Решение |
|---|---|
| Тонгги дастурхон: «6:00» лежит на тёмном плове, плов — крупный план на весь экран | Время теперь под фото; плов заменён на целое блюдо сверху (квадрат, рваный край) |
| Тонгги дастурхон: чай — серое фото со шторой | Заменено на тёплый стакан чая в солнце |
| Боғ: белые тюльпаны дважды, «похоронное» настроение | В круге — розовые тюльпаны в белой вазе; внизу белые остались |
| Боғ: рваный край как у Тонгги дастурхон | В Боғ — скруглённая рамка; рваный край остался только у наҳорги ош |
| Боғ: два одинаковых блока адреса подряд | Второй адрес — справа, без заливки, тонкой линией |
| Ипак: имена сложены так же, как в Муҳр | В Ипак оба имени слева, «ва» в строке невесты; у Муҳр — лесенка лево/центр/право |
| Ипак: дата прижата к «18:00», «йил» один в строке | День недели и дата — отдельными строками, больше отступ |
| Ипак: латунные подсвечники — «западный интерьер» | Заменено на фото шёлка |
| Муҳр: монограмма наполовину на фото, плохо видна | Монограмма столбиком на поле слева от арки |
| Муҳр: плоский конверт и печать | Тон бумаги с тенью сгиба, сургуч с объёмом (без блеска) |

## Что оставлено как есть (и почему)

- Календарь и тонкие цифры таймера есть на страницах — критик их не увидел, потому что они попали между кадрами.
- «30» одно в последней строке — так выглядит ноябрь, это не ошибка вёрстки.
- Общие элементы (плашка InviteIZI, кнопка музыки, футер) — одинаковые на всех шаблонах сайта.
- Текст приветствия Боғ («…наҳорги ошга») собирается из примерных данных демо (первый тадбир — наҳорги ош); у клиента текст строится по его тадбирам.
- Западные стоковые фото пары (кольца, букет): без лиц, но лучшая замена — фото самого клиента (шаг «📷 расмлар» в боте) или картинки Higgsfield (см. docs/design/higgsfield-todo.md).
