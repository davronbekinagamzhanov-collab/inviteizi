### Скорость бота: было → стало

Замер — настоящий код бота на изолированной PostgreSQL (`bot/speed.bench.test.ts`). Время сети в проде ≈ число запросов × задержка до Supabase (оценка — 30 мс на запрос).

| Шаг | Запросов к БД было → стало | Оценка сети было → стало |
|---|---|---|
| /start (новый) | 2 → 2 | ~60 → ~60 мс |
| выбор языка | 15 → 7 | ~450 → ~210 мс |
| /start (знакомый) | 23 → 9 | ~690 → ~270 мс |
| каталог | 2 → 2 | ~60 → ~60 мс |
| тадбир Никоҳ | 16 → 8 | ~480 → ~240 мс |
| новый клиент: /start → язык → каталог → Никоҳ (4 обновления) | 34 → 17 | ~1 020 → ~510 мс |
| сводка → «Тасдиқлаш» (создание заказа) | 21 → 15 | ~630 → ~450 мс |
| «💳 Тўлаш» | 20 → 12 | ~600 → ~360 мс |
| «✅ Ҳаммаси тўғри» | 23 → 15 | ~690 → ~450 мс |
| «✅ Тўладим» | 11 → 10 | ~330 → ~300 мс |
| имя из Kaspi | 18 → 16 | ~540 → ~480 мс |

Что было причиной и что сделано:
- **Роль человека проверялась 4 раза за одно обновление** (админ? менеджер? партнёр? — по 3–4 запроса, плюс каждый раз UPDATE привязки партнёра). Теперь — один раз (`bot/repo-memo.ts`, кэш сбрасывается при любой записи), админ и менеджер проверяются одновременно, партнёр — одним запросом.
- **`pg_advisory_xact_lock(hashtext($1))` — 162 мс в среднем** — это ожидание чужой блокировки. Брались в двух местах: при создании заказа (адрес `aziz-madina`) и при ответе гостя. Обе — только внутри транзакции базы, вызовов Telegram под ними нет (проверено по коду). Создание заказа теперь без блокировки: адрес уникален в самой базе, при совпадении берётся следующий (8 одновременных заказов «aziz-madina» → 8 разных адресов, тест на PostgreSQL). В ответах гостей блокировка только на «посчитать лимит и вставить»; исправление своего ответа — без блокировки.
- **У вебхука `max_connections 1`**: пока одно обновление строит PDF или постер (2–5 с), ждут все клиенты. Теперь файлы «Сақлаб олиш» и постер партнёра строятся после ответа Telegram (`after()` Next.js): кнопка отвечает «⏳» сразу, файл приходит следом.
- **Метрика**: обновление дольше 3 с → запись в `bot_errors` (step `slow`, шаг, мс), не чаще раза в 5 минут; утренняя проверка пишет число медленных за сутки (от 3).

## 3. Что проверить на телефоне

1. **Владелец:** Mini App «InviteIZI · Админ» — сверху «Сегодня» и «Ждут проверки оплаты», нажмите — экран прокрутится к чекам; «📋 Подробнее» — таблица по дням.
2. **Партнёр:** откройте новую ссылку `join_` с другого аккаунта — одно приветствие, выберите язык — меню из 4 строк; «💳 Kaspi рақамим» — введите номер.
3. **Партнёр:** «📋 Батафсил» — по дням, без имён клиентов; «❓ Қандай ишлайди» — 5 строк.
4. **Клиент:** откройте своё оплаченное приглашение, ответьте «Келаман» с тилаком — вечером тилак придёт в отчёте; в «Менинг таклифномаларим» кнопка «📝 Жавоблар · N киши».
5. **Клиент:** «📥 Сақлаб олиш» → «🖨 PDF A5» — кнопка сразу отвечает «⏳», файл приходит через пару секунд.
6. **Оптовик:** оплаченный заказ → «📤 Мижозга юбориш» → ссылку откройте с другого аккаунта — заказ перешёл.
