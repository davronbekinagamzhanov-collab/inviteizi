# Сўзана медальон — художественная доработка PR #14

Основа 66b5e53bf1a4bee7e8c01289e2e672434d479816, только feature/nikoh-simple-polish. Цель — исправить отклонённые встроенные фотографии, не менять остальные шаблоны или формат.

## Материалы и композиция

Все три прежних defaults b3-suzani / w-peony-garden / x-roses-vase заменены. По прямому заданию владельца использован доступный image_gen: это **сгенерированные фотореалистичные изображения**, не реальные документальные фотографии и не нарисованные CSS/SVG сцены. Это узкое разрешение на генерацию для данного шаблона заменяет исторический общий запрет AGENTS только здесь.

Набор: крупная деталь ручной вышивки сюзане с миндальным цветом и хлопковой бумагой; мягкие складки вышитого льна вокруг чистого листа; перевязанное узкой матовой лентой свадебное фолио на той же ткани. Палитра общая: неокрашенный лён, молочный, приглушённая марена, шалфей. Свет слева, мягкие реальные по характеру тени, заметные нити и волокна. Нет людей, текста, логотипов. Вариант с кольцами был отклонён при внутренней художественной приёмке, заменён полиграфическим фолио. Используемые исходные PNG сохранены без изменений в workspace. Обложки/thumbnail/OG только этого шаблона обновлены из нового основного кадра; оптимизированные WebP и provenance с источниками/хешами — public/art/suzani-medalyon.

Маленький пёстрый круг и искусственно арочная карточка заменены крупной фотографической полосой и спокойным прямоугольным печатным листом. Короткие имена стоят одной строкой, длинные сохраняют вертикальную читаемую раскладку. Два события на ширине от 375 px — соседние колонки; на меньшей ширине — обычные строки. Третье событие занимает всю ширину. Карты доступны с прежними круглыми целями 44 px. Две дополнительные фотографии — согласованные широкие детали внизу того же листа. Нет конверта, анимации, countdown, экранной истории или новых блоков.

## Совместимость и изоляция

Сохранены три замены клиентом (полная/частичная): собственный URL имеет приоритет; незаполненные места получают новые встроенные кадры. Для собственной главной фотографии используется contain/центр, чтобы не обрезать пару. Никакой загрузки в Storage или изменения заказа не выполнялось.

Изменения общей Card и CSS ограничены textile-веткой; DOM и стили Оқ мактуб не меняются. Реестр, цены 5000, формат Simple, API, маршруты/данные заказов, музыка/карты/языки/RSVP, main, VIP-ветка и PR #13 сохранены. Атрибуции старой фотоподборки для этого шаблона больше не выводятся, поскольку эти фотографии не используются.

## Художественная приёмка и QA

Исходная версия 390 px сохранена до работы. Новая композиция сравнивается с ней до публикации: вместо крошечной фотографии и случайных цветов/вазы — крупный натуральный материал, единая история свадебной печати и согласованная типографика. Результат не сводится к новой рамке/цвету.

Профильные tests проверяют новые три defaults, отсутствие старых слотов, полную/частичную замену фотографиями клиента, direct Simple, события/поля и прежние paid-route fixtures. Browser QA: 320/360/375/390/430, UZ/RU, отсутствие gate/timer/overflow, загрузка фото, музыка и реальные переходы карты. Дополнительный DOM-layout тест проверяет длинные имена, площадки и клиентские фото без записи реальных заказов. Прямая Share-ссылка проверяется в чистом контексте на точном новом READY.

Итоговые SHA/deployment, фактически выполненные проверки и ограничения фиксируются в PR. Физический Safari/iPhone, нативный 2ГИС и настоящая Telegram/Storage-загрузка не проверяются. Нет merge или production deploy. После приёмки Preview работа останавливается.

Локальный итог перед коммитом: 13 профильных тестов + 2 budget-теста PASS; ESLint, TypeScript и production webpack build PASS. Browser: 10/10 default cases (два Simple × пять ширин), 5/5 дополнительных DOM-layout fixtures с длинными полями/тремя событиями/фотографиями клиента. Полная и частичная подстановка URL проверена отдельно компонентными тестами. Оқ мактуб прошёл те же функциональные проверки; полное пиксельное совпадение снимков не подтверждено, изменения его разметки/стилей отсутствуют. Финальная художественная сверка старого и нового 390 выполнена: новая крупная фактурная полоса, типографика и три согласованных кадра приняты к Preview.
