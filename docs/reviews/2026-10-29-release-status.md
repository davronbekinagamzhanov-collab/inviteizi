Вместо next/font/google используется next/font/local. Семейства, нормальные/курсивные начертания, запрошенные веса и CSS-переменные сохранены. Загрузчикам даны уникальные идентификаторы: установленный Next.js использует их для font-family, одинаковые display/body в разных модулях могли бы смешать семейства. Preload отключён для загрузки только реально используемых на странице шрифтов. Содержимое и композиция приглашений, анимации, цены и бизнес-логика не менялись. Полные шрифты могут быть крупнее прежних сетевых подмножеств; мобильную производительность в Vercel Preview ещё нужно проверить. Коммитятся готовые WOFF2: Python/fontTools/Brotli для обычной установки и сборки не нужны. package.json и lockfile не изменены.

## Блокер Merge / внешних проверок

В текущей среде пользовательский allowlist сети не применён (`allowed_hosts: []`, package-manager presets активны). Фактические запросы дают:

- GitHub: `gh pr list --head feature/owner-analytics-design-audit` → `Post https://api.github.com/graphql: Forbidden`.
- Vercel API: CONNECT к api.vercel.com → 403.
- Существующий сайт: CONNECT к inviteizi.vercel.app → 403.

Поэтому невозможно надёжно найти/создать PR, проверить GitHub Checks, Vercel Preview/Ready, выполнить внешние production smoke или проверить действующий Telegram /dashboard. Это сетевые отказы среды, а не доказательство отказа приложения или отсутствия токенов. Новый токен не запрашивался: сначала требуется разрешить штатный доступ, затем повторить операции с имеющейся аутентификацией.

Дополнения api.github.com, api.vercel.com, inviteizi.vercel.app сохранены в черновике настроек среды с сохранением прежних доменов. Обновлён start_skill для локальных шрифтов и smoke. Сохранение черновика не меняет текущую сеть и не публикует среду. Нужно применить сетевые настройки; после успешного доступа проверять точный Preview hostname из реального deployment и при необходимости разрешить именно его.

**Merge не выполнен:** требуемые пользователем внешние проверки недоступны. Production deployment не запускался. После снятия блокера: найти/создать PR, проверить конфликты и Checks на последнем SHA, Preview и приватность аналитики; только при успехе Merge, дождаться Vercel Production Ready на новом main SHA и выполнить безопасный smoke. Платёжные сценарии и рабочую БД не трогать.
