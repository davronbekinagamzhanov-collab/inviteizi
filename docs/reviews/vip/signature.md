У каждого ровно три крупные свадебные фотографии в единой серии. Нет снимков залов, мелких фотокружков, dress code или выдуманных пунктов программы. У обеих свадеб сохраняются три места для фотографий клиента: каждое загруженное изображение заменяет только своё место, незаполненные места сохраняют согласованные образцы. Четвёртый снимок не используется; при ошибке загрузки восстанавливается локальный образец.

Имена и латинские инициалы, даты, 1–3 события, места, адреса, карты, текст приглашения, музыка и RSVP берутся из общего движка. Основной адрес — фактический `nikohBazm`, при его отсутствии первое событие; утренний ош и остальные события сохраняются в программе. У «Заррин аҳд» карта основного события не дублируется в программе. Каждый реальный адрес имеет одну кнопку карты.

На время заставки содержимое inert, скролл открывается после завершения. Повторное касание не запускает вторую анимацию. Изображение обложки декодируется заранее с локальным fallback; есть повторная попытка. Музыка стартует только в обработчике касания. Reduced motion открывает сразу; доступно открытие с клавиатуры. На кадрах перехода нет перевёрнутого текста, выезжающего листа или белой вспышки.

## Проверки

Полный набор: **1067 тестов прошли, 79 штатно пропущены**. TypeScript, ESLint, Next production build. Новые тесты проверяют отличающийся порядок разделов, латинские монограммы, три локальных фото, частичную замену, длинные имена, пользовательский текст, три события, единственную карту каждого события и сохранность цен/принятого каталога.

Браузерный сценарий: `scripts/vip-signature-qa.mjs`. По умолчанию проверяет только эти два новых VIP, требует настоящий HTTPS `VIP_ORIGIN`; localhost разрешается только явным `VIP_ALLOW_LOCAL=1`. Сохраняет фактический origin, SHA и deployment ID. Мобильные 320/360/390/430 px; открытие, двойное касание, клавиатура, reduced motion, три загруженных изображения, календарь, фактическое воспроизведение/пауза/повтор музыки, скролл до конца, языки, все ссылки карт и реальное нажатие на карту, ошибки консоли и горизонтальный скролл. На 390 px дополнительно снимает четыре промежуточных кадра для визуальной проверки. Локальные артефакты и Share-параметры не коммитятся.

Ограничения: Chromium mobile emulation, без физического iPhone/Safari и запуска нативного 2ГИС. 2ГИС может показывать CAPTCHA автоматическому браузеру. Реальная загрузка через бот, продажи и отправка RSVP в рабочую БД не выполняются. Проверки замены фото используют тестовые данные без заказов.

## Изображения

Две новые согласованные серии созданы OpenAI Image Generation по прямому заданию владельца; дополнительные кадры созданы с референсом первого кадра своей серии. Это разрешённое владельцем исключение из старого запрета AI-фото в AGENTS.md. Все изображения — иллюстративные свадебные образцы, не снимки реальных клиентов или их банкетных залов. Лица не идентифицируются. Отдельные материалы: свадебная шёлковая вуаль и хлопковая винная бумага со слепым тиснением. WebP подготовлены заранее; новая Vercel Image Optimization не используется.
