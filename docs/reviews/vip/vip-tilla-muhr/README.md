# VIP-1 · Тилла муҳр

Закрытое демо: `/demo/vip-tilla-muhr`. Концепция тарифа — 10 000 ₸; рабочие цены, ACCEPTED и каталог не менялись. Публикация и merge не выполнялись.

Полноэкранный конверт из слоёв бумаги, золотая печать с инициалами заказа, 3D-клапан, выдвижение фотокарточки и уход конверта. Перед движением декодируются hero, flowers, paper, flap, seal и загружаются локальные шрифты. Повторное нажатие заблокировано; при ошибке загрузки предлагается повтор.

После открытия: фото с именами, журнальное приглашение, календарь с контуром сердца, фотографии деталей, волнистая программа с сердцем, два ракурса декоративного зала на каждое место, стандартная RSVP и финальная подпись семьи. Программа, даты, названия, адреса и карты — только из useInvitation, без придуманных событий. В исходном свадебном образце два события; длинный образец проверен с тремя.

## Проверка

- В таблицах cmap всех трёх локальных шрифтов проверены ў, қ, ғ, ҳ и прописные формы: все присутствуют.
- Скриншоты 390×844 и 360×740; дополнительно 320×740, 375×812, 430×932.
- Конверт, три фазы открытия, все секции, три позиции сердца, длинные имена и reduced motion — рядом с этим файлом.
- `opening-and-scroll.webm` — запись Playwright. `verification.json` — измерения кадров через requestAnimationFrame при CDP CPU throttling 4×, без записи и скриншотов во время замера.
- Форма проверяется через существующий `/dev/invitation/vip-tilla-muhr?mode=demo&long=1`: preview не отправляет данные. Заказы с rsvpSlug используют существующую форму оболочки. У обычного `/demo` исходные образцы проекта не содержат rsvpSlug.
- Музыка, языки, подсказка открытия и бренд — из общего каркаса. Для тестового Chromium доверие к сертификату прокси ограничено SHA-256 SPKI ключа CA, переданного средой; глобальное отключение TLS не используется.

## Честные ограничения

- Проверено в Chromium с мобильным viewport; реальный iPhone/Safari не доступен в этой среде. Сохранены perspective, preserve-3d и обе backface-visibility для Safari; это не заменяет проверку на устройстве.
- Фотографии сгенерированы по текущему заданию (исключение из прежнего запрета AI-фото в AGENTS.md). Изображения залов — декоративные, это явно подписано в приглашении. Лиц нет.
- Фото деталей получены из девятикадрового исходника, полноэкранный hero — из отдельного вертикального кадра. Для печати или сильного зума детали стоит генерировать в отдельном высоком разрешении.
- Фото клапана сохранено в наборе и декодируется, но анимируемый клапан собран CSS из фактуры бумаги, чтобы тень и геометрия соответствовали движению.
- Тариф 10 000 ₸ документирован как концепция, продажа и платежи не подключены по ограничению задания.

## Результат финальной проверки

Production-сборка: открытие **58.45 FPS**, программа **60 FPS** при CPU 4×. Консоль без ошибок. Линтер, `tsc --noEmit`, `next build` пройдены; 83 файла / 1036 существующих тестов пройдены, 79 тестов штатно пропущены. Сердце: прогресс 0,16 / 0,50 / 0,84, три разных transform.
