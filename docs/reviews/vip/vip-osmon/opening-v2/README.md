# Осмон · открытие v2

[Конверт](390-envelope.png) · [Печать](390-01-seal-crack.png) · [Внутренняя сторона клапана](390-02-flap-lining.png) · [Лист с именами](390-03-sheet-names.png) · [Уход конверта](390-04-envelope-depart.png) · [Видео](opening.webm)

Фотографическая хлопковая бумага, плотный край и контактные тени, сургуч 34% ширины. Этапы выполняются последовательно через await завершения анимаций: трещина печати → поворот клапана с узором → прямоугольный лист → уход конверта вниз → мягкое раскрытие существующей обложки. Имена не показываются через диагональную прорезь; новый лист не содержит дополнительной фотографии.

В конце открытие полностью завершается до освобождения прокрутки. Перед движением декодируются материалы, печать и первые изображения страницы; музыка запускается исходным нажатием. Reduced motion открывает приглашение сразу после готовности материалов.

Проверка 390×844, 360×740, 320×740, 375×812, 430×932; Enter с клавиатуры; порядок всех этапов; нет горизонтального скролла. Один переключатель языка в шапке, ни одного поверх Манзил — [скриншот](390-venue-single-header-control.png). Объём и порядок фотографий страницы ниже не менялись.

Production-сборка, Chromium, CPU 4×: **59.01 FPS**, p95 **16.7 мс**, ошибок консоли 0. Замер отдельно от видео и скриншотов. Полные данные — [verification.json](verification.json). Физический iPhone/Safari не проверен.
