# VIP atelier — четыре новых приватных варианта

Рабочая ветка `feature/vip-invitations`, PR #13. Новые страницы находятся рядом с тремя существующими темами в `templates/themes/`; изображения — в `public/vip/`.

| Страница | Композиция и открытие | Фотографии |
|---|---|---|
| `/demo/vip-marvarid` — Марварид | Светлая бумага, латинская монограмма, асимметричный фотопортрет; верхняя и нижняя части обложки расходятся. Обложка → письмо → фото → календарь → адреса → фото → программа → благословение. | Три заменяемых места, все три с локальными образцами. |
| `/demo/vip-bogi-visol` — Боғи висол | Сад, оливковый фон, парные створки с перспективой; календарь перед письмом. Обложка → календарь → фото → письмо → программа → фото → адреса → благословение. | Три заменяемых места с локальными образцами. |
| `/demo/vip-oq-tulpor` — Оқ тулпор | Мальчик в узбекском чапане и дўппи на белом коне; светлая заставка с силуэтом коня поднимается. Обложка → письмо → программа → календарь → благословение → адреса. | Один встроенный портрет; `photos` заказа игнорируются, `clientPhotos:false`. |
| `/demo/vip-umr-ziyosi` — Умр зиёси | Тёплый семейный альбом, крупный возраст из данных, розы и чай; обложка поворачивается вокруг корешка. Обложка → письмо → фото → благословение → календарь → программа → адреса → фото. | Три заменяемых места; в образцах нет лиц. |

Латинские инициалы свадебных вариантов присутствуют на закрытой заставке и после открытия. Используется существующая транслитерация проекта; нет жёстко записанных A/M. Имена, возраст, текст приглашения, 1–3 события, даты, адреса, музыка и RSVP используют общий движок. Четвёртая фотография не используется. Портретный клиентский снимок не обрезается агрессивно при большом несовпадении пропорций; при ошибке загрузки используется локальный образец.

Новые открытия — 1,65 с движения с мягким замедлением. У прежних «Тилла муҳр», «Осмон», «Сўзана» движение увеличено с 1,05 до 1,4 с, короткая реакция печати с 0,16 до 0,2 с. Их композиции и фотографии не менялись. Листа, который выдвигается из конверта, нет. Повторное касание не запускает переход заново; reduced motion открывает сразу. Музыка запускается в обработчике касания.

Все четыре ID остаются вне `ACCEPTED`, порядок и цены каталога сохранены. Зарегистрированы №145–148; действующих дизайнов по-прежнему 36. Main, production, бот, API, Supabase, действующие заказы, зависимости, env и настройки хостинга не менялись.

## Проверки

TypeScript, ESLint и Next production build. Полный набор: 1060 тестов прошли, 79 штатно пропущены. Новые тесты проверяют транслитерацию, три фото и частичную замену, неизменяемый суннат-портрет, разный порядок секций, длинные данные с тремя событиями, реальные адреса и неизменность каталога/цен.

Локальная production-сборка проверена браузером на 320, 360, 390, 430 px для четырёх новых страниц: открытие, три/одно фото, музыка с паузой и повторным запуском, календарь, прокрутка, переключение языка, кнопки 2ГИС, отсутствие ошибок консоли и горизонтальной прокрутки. Фотографии просмотрены визуально. После READY тот же `scripts/vip-shots.mjs` проверяет все семь страниц на точном HTTPS deployment, дополнительно — двойное касание, клавиатуру и reduced motion. Отчёт записывается вне репозитория; параметры Vercel Share не коммитятся.

Ограничения: Chromium mobile emulation, физический iPhone/Safari и запуск нативного 2ГИС не проверяются. 2ГИС может показать CAPTCHA автоматическому браузеру. Загрузка из настоящего бота и реальные ответы RSVP не отправляются. Слотам фото передаются тестовые данные без создания заказов.

## Происхождение новых изображений

Четыре оригинальных изображения созданы инструментом OpenAI Image Generation по прямому заданию владельца в этой задаче; это явно запрошенное исключение из старого запрета AI-фото в AGENTS.md. Сцены: свадебный шёлк/жемчуг/магнолия; тихий сад с фатой; ребёнок в узбекской праздничной одежде на белом коне; семейный альбом, розы и пиала без людей. Это иллюстративные образцы, не фотографии реальных клиентов или банкетных залов. WebP подготовлен заранее, без Vercel Image Optimization.
