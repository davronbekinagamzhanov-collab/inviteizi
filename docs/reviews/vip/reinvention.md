## Ипак зиёси — Cinematic Silk Ceremony

- Собственные Design, Opening, CSS и гарнитуры; прежний общий визуальный конструктор не используется.
- Закрытая сцена из трёх пространственных шёлковых слоёв с фотографической фактурой. После жеста расходится узел, ближний слой движется влево и вверх, дальний — вправо и вверх, полупрозрачный — вниз. Перспектива, разные точки вращения и задержки создают последовательное раскрытие. Движение занимает около 1,62 с; фотографии и шрифт декодируются заранее.
- Главная сцена — полноэкранный световой кадр с вертикальным ритмом имён и переплетёнными латинскими инициалами. Вторая фотография становится удерживаемой сценой: при прокрутке шёлк закрывает её, открывая календарь. Это один переход изображения в информацию, а не отдельные карточки.
- Дальше — программа как свободная временная линия, адреса вдоль открытых изгибов ткани, третья фотографическая сцена, каллиграфический финал.
- Три клиентских места сохранены. Лица клиента не ограничиваются; демонстрационные кадры без видимых лиц. При сбое фото используется локальный fallback. Для клиентских фото отключены дополнительное увеличение и движение; очень широкие снимки сохраняются существующим VipImage.

## Зарбоф — Grand Wedding Ceremony

- Отдельные компоненты, CSS, Libertinus Serif и PT Sans; собственная геометрия и ритм, без импорта визуальных секций первого VIP.
- Закрытая архитектурная композиция: рифлёные боковые опоры, ступенчатые верх и основание, центральный рельефный медальон. При касании медальон уходит, верх и основание расходятся вертикально, затем опоры раскрывают боковые части сцены. Это четыре элемента с иной пространственной механикой, движение около 1,57 с.
- В открытой сцене — монументальные инициалы, круглый архитектурный просвет и предметный натюрморт, растворённый в пространстве. Нет арки с отдельной карточкой внутри.
- Порядок: главная сцена → ступенчатая программа → календарь-циферблат → адреса с архитектурными линиями → обращение и предметная сцена → третий натюрморт → финальный герб с датой.
- Во всех трёх изображениях нет людей, фигур, силуэтов и рук. Клиентские фотографии по-прежнему игнорируются.

## Материалы и совместимость

`ceremony-1/2/3.webp` и `ceremony-silk.webp` — новая согласованная серия, созданная инструментом OpenAI image generation для этой задачи. Оригиналы сохранены в рабочем каталоге generated_images; для сайта экспортированы WebP шириной 1000 px. Это искусственно созданные демонстрационные сцены, не фотографии реальных клиентов. Новые материалы не содержат переводимых надписей. Суммарный вес четырёх WebP — около 508 КБ.

Старые 1/2/3.webp Ипак зиёси, на которые ссылается Сўзана, сохранены побайтно. У Зарбоф сохранены прежние три предметных изображения. Дополнительно создан материал `ceremony-architecture.webp`: фотографическая архитектурная сцена без людей, рук, надписей и символов. Он служит общей фактурой четырёх частей открытия и открытой сцены; три предметных снимка остаются отдельными. Источник — OpenAI image generation для этой задачи. Локальные шрифты распространяются с существующими OFL-лицензиями; fontconfig подтвердил ў/қ/ғ/ҳ в используемых начертаниях.

Общими остаются только прежние бизнес-функции и технический useCeremony: загрузка, повтор при ошибке, синхронный запуск музыки по жесту, блокировка двойного касания, reduced motion и завершение состояния. Нет физической симуляции ткани, WebGL, новых зависимостей и бесконечных эффектов. Движение фотографий/занавеса использует Motion Values без React setState на каждом кадре. Анимации разделов ограничены одним появлением. Имена подгоняются под ширину и количество слов.

Сохранены UZ по умолчанию, ручной RU и явный язык URL, реальные события/даты/адреса/карты, музыка, предусмотренный RSVP. Не добавлялись dress code, события, новые данные заказа и рекламные разделы. Первые три, Висол нури / Заррин аҳд, остальные шаблоны, каталог, Mini App, цены, бот, API, Supabase, main и production не изменяются.

## Проверка и публикация

`scripts/vip-reinvention-qa.mjs` проверяет оба маршрута на 320/360/375/390/430 px: открытие, двойной жест, reduced motion, Enter, язык, три фотографии, календарь, фактическое воспроизведение музыки, карты, прокрутку, консоль, переполнение и сдвиги компоновки при открытии. На 390 px сохраняет закрытую сцену, промежуточные кадры, каждую крупную сцену и русский вариант информационных разделов.

Локально TypeScript, ESLint, production build и 1075 тестов прошли (79 пропущены). На пяти ширинах оба маршрута прошли функциональный QA: сдвиги компоновки открытия 0, p95 интервалов requestAnimationFrame в изолированном Chromium около 17 мс. После визуальной проверки введена дополнительная геометрическая проверка: текст всех дат Зарбоф остаётся внутри циферблата. Эти измерения не гарантируют аналогичную частоту кадров на физическом телефоне.

Итоговые результаты TypeScript/ESLint/build/Vitest, точный SHA, deployment READY и проверка опубликованных HTTPS-страниц фиксируются в PR #13. Share URL не сохраняется в Git. Публикация через подключённый GitHub API владельца без авторских overrides; production и merge запрещены.

Ограничения: Chromium с мобильными viewport не является физическим iPhone/Safari и не доказывает плавность на каждом устройстве. Нативный запуск приложения 2ГИС, реальные загрузки через бот и отправка RSVP в рабочую БД не выполняются; интеграционные тесты без подходящей БД пропускаются. У 2ГИС возможна внешняя captcha.
