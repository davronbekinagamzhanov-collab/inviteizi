# Complete premium redesign, pinned order versions and six catalog additions

Новые заказы теперь сохраняют premium-v1 через PostgreSQL и открывают оформление, показанное в каталоге. Старые заказы остаются на Legacy; при редактировании старого неоплаченного заказа используются соответствующие исходные обложки и демо. Версия, сохранённая сумма и персональная ссылка не меняются при обычных правках и оплате.

Сохранены пять Animated первого этапа, переработаны три Simple и два Scroll, добавлены ровно шесть дизайнов других категорий. Активный каталог — 56, все прежние 50 ID/номеров/цен сохранены. Порядок отображения отделён от номеров. Добавлены 12 оригинальных инструментальных MP3 с исходными партитурами/CC0-декларацией; никакие существующие треки или пользовательские песни не скрывались.

Google Fonts self-hosted из официального источника с OFL, поэтому production build работает без Google Fonts API. Обновлены обложки, версионированные OG и доказательства визуальной проверки.

Проверки: 804 passed / 30 skipped (реальный Supabase), TypeScript и ESLint без замечаний, production build успешен; 256 мобильных сценариев, 92 dev/Legacy, 82 production smoke, 12 реальных MP3, 16 font/CLS проверок. Постоянные 60 FPS и физические телефоны не заявляются.

До Merge владелец принимает визуальную часть и проверяет/применяет nullable design_version migration и узкий INSERT шести шаблонов. Музыкальные INSERT — только после deploy и доступности MP3 на существующем домене. SQL в Production не выполнялся. Merge и Production Deploy агентом не выполнялись.
