## 6. Известные ограничения

- Реальный звук на телефонах по-прежнему виден только в журнале `bot_errors` (step = `audio`).
- Vercel Hobby — некоммерческий тариф; Pro — позже, решение владельца.
- Фото и PDF строятся на сервере за 1–4 с (Satori + sharp, без браузера); видео — только в GitHub Actions.
- «Подложки» дизайнов сняты один раз скриптом `scripts/keepsake/capture-looks.ts` (dev-сервер + Playwright). Если дизайн перерисуют — снять его заново: `KEEPSAKE_BASE=http://localhost:3121 npx tsx scripts/keepsake/capture-looks.ts <id>` и `npx tsx scripts/keepsake/refine.ts`.
- Слово «Печать» из задания в узбекском интерфейсе заменено на «Чоп этиш» (один язык на экране).
