# Выпуск ветки feature/natural-pilots (PR #8) — порядок для владельца

Обновлено 04.11.2026 (финал: фото, проверки). Всё ниже — только после вашего «да». SQL-файлы с 03.11 не менялись.

**Как запускать SQL:** Supabase → ваш проект → **SQL Editor** → New query → вставить файл целиком → **Run**.
Каждый файл можно запускать повторно: второй раз ничего не меняет. Если номер дизайна в базе уже занят чужим — файл
сам откатывается и пишет «conflict», ничего не ломая.

**Почему такой порядок.** Сайт и бот берут список дизайнов из кода. Таблица `templates` в базе — справочник для заказов
(заказ ссылается на строку дизайна). Поэтому строки новых дизайнов кладём ДО выкладки кода: старый бот их не видит,
а новый сразу может принять заказ.

Что уже было в прошлых выпусках (в `main`) и повторно не нужно: миграции `bot_errors`, `partners`, `rsvp`,
`rsvp_flag`, `design_version`. Если вы их ещё не применяли — сначала они (по порядку дат в имени файла).

## 4. Проверка в боте (10 минут, платить не нужно)

1. `/start` → «💌 Таклифнома яратиш» → **Никоҳ**: 3 формата — Анимацияли 8 000, Варақланадиган 6 000, Оддий 5 000.
2. В каждом формате листаются обложки ◀ ▶; у дизайнов с фото — значок фотоаппарата на обложке и строка «📷 …».
3. **Наҳорги ош**: во всех трёх форматах **нет** значка 📷 и строки про фото; в анкете нет вопроса про фото.
4. **Никоҳ → Оддий → «Ипак альбом»** (с фото) → дойти до «📷 Таклифномага расмларингизни қўшасизми?» → «✅ Ҳа» →
   отправить 1 фото → «✅ Тайёр» → … → «✅ Ҳаммаси тўғри» → ссылка с «НАМУНА», фото на первом экране.
5. В том же заказе: «✏️ Ўзгартириш» → «✏️ Дизайн» → **Анимацияли** → любой дизайн → «🛒 Сотиб олиш» → «✅ Ҳаммаси тўғри».
   Кнопка оплаты теперь **8 000 ₸**, ссылка та же.
6. Ещё раз «✏️ Дизайн» → **Оддий** → дизайн с фото → бот сам спрашивает про фото. Цена снова 5 000 ₸.
7. Открыть ссылку НАМУНА на телефоне: музыка включается и выключается кнопкой, надпись «НАМУНА» есть.
8. В том же заказе: в каталоге «🤍 Севимлиларга» на другом дизайне → «✏️ Ўзгартириш» → команда /favorites → «🛒 Сотиб олиш» под этим дизайном → в каталоге ещё раз «🛒 Сотиб олиш» → «✅ Ҳаммаси тўғри» — заказ тот же
   (ссылка не меняется, второго заказа в «Менинг таклифномаларим» нет).
9. Проверка оплаты (по желанию, на своём аккаунте): «💳 Тўлаш» → отправить любой скрин как чек → вам как админу
   приходит карточка → **«Рад этиш»** → клиенту приходит причина → чек можно отправить заново. Подтверждать не обязательно.
   Если после «Тўлаш» сменить формат — старая кнопка «Чекни юбориш» покажет реквизиты с новой суммой.
