## 2. Переменные Vercel (Settings → Environment Variables → Production)

| Переменная | Значение | Смысл |
|---|---|---|
| `MINI_APP_ENABLED` | не задавать (= включено) или `false` | `false` — «✨ Таклифнома яратиш» ведёт заказ в чате, `/app` отвечает 404 |
| `KAZAKH_ENABLED` | **не задавать** (выключено), пока носитель не проверит тексты | `true` — кнопка «🇰🇿 Қазақша» в боте, ҚЗ в приложении, казахский постер и язык приглашения |

Изменили переменную → **Deployments → … → Redeploy** (демо-страницы собираются при выкладке).

## 3. Merge и выкладка

1. GitHub → PR из `feature/v2` → **Merge**. Vercel выложит сам (3–5 минут), дождаться **Ready**.
2. **Проверка домена** (1 ноября был откат — после отката Vercel перестаёт сам переводить домен на новые выкладки):
   Vercel → проект `inviteizi` → **Deployments**. Если сверху жёлтая плашка «Production domains are not being
   automatically assigned» или у новой выкладки нет метки **Current** — нажмите на новой выкладке **… → Promote**
   (или **Undo Rollback**). После этого домен снова переходит сам. Проверка: открыть `inviteizi.vercel.app/app` —
   страница приложения (не 404).
3. Кнопка меню у всех: в терминале
   `node --env-file=.env.local scripts/telegram-setup.mjs --menu` — у поля ввода появится «✨ Очиш» (открывает приложение).
   При `MINI_APP_ENABLED=false` та же команда вернёт обычное меню команд. Webhook и профиль не меняются.
4. Если включили казахский: `node --env-file=.env.local scripts/telegram-setup.mjs --commands` — команды бота на казахском.

## 4. Назначить менеджера

Бот → «👋 Панель» → **⚙️ Настройки** → **➕ Менеджер** → бот даст ссылку `t.me/…?start=mgr_…` (одноразовая, 72 часа).
Отправьте её другу лично. Он открывает — становится менеджером. Снять: ⚙️ Настройки → «❌ Снять: @…».

## 5. Тест в боте после выкладки (10 минут, с двух телефонов)

1. Второй телефон (как клиент): `/start` → язык → «✨ Таклифнома яратиш» → приложение → дизайн → имена, дата →
   «🌐 Тиллар»: включить «Русча», главный язык РУ, «👁 Мисол» → НАМУНА открывается по-русски, переключатель ЎЗ · РУ.
2. «Тўлашга ўтиш» → загрузить любой скриншот как чек → у вас в боте чек → **✅ Тасдиқлаш** →
   в ответе строка «💳 №… · сумма · дизайн · напрямую», клиенту — ссылка без «НАМУНА».
3. Ссылку открыть на телефоне: первый тап по странице включает музыку, круглая кнопка выключает/включает.
4. «👋 Панель» → «📊 Статистика»: Сегодня → оплата видна; «📤 Выгрузка» → «📥 Скачать Excel» открывается в Excel.
5. Партнёр: «🤝 Партнёры» → ➕ → создать с собой как партнёром (ставка 500) → ссылку `join_` открыть со второго
   телефона → номер → Kaspi → меню партнёра; «🔳 QR ва постер» → PDF/PNG.
6. В 20:00 придёт «📋 Итоги дня» (или «сегодня тихо»). В день выплаты в 10:00 — «💰 Выплаты сегодня» с кнопками ✅.
7. Тестовый заказ после проверки можно оставить — заказы владельца и менеджеров в статистику не попадают.
