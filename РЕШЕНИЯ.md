- Новое задание: 60 готовых разных дизайнов всего, продолжать существующие ветку и PR #1 партиями. Настоящие фото с проверенными источниками; AI-фото не использовать. До 320 px включительно и измерение кадровой плавности добавить в проверку.

- Не помещать открытый Telegram ID в URL: использовать непрозрачный AES-GCM-маркер во фрагменте ссылки.
- Сохранить одобренные 9 дизайнов. Не включать заглушки и не объявлять перекраски новыми качественными шаблонами ради числа 50.

- Для OG не использовать скриншоты с чужими примерными именами: подготовлены отдельные обложки из существующих материалов.
- Исправить выявленный сборкой сбой Lora локальным хранением того же шрифта; заменить CSS-loader на стандартный Tailwind PostCSS из документации установленного Next.js.
- Полное содержание предыдущего мастер-промпта отсутствует: не придумывать неизвестные требования. Нереализованные пункты дополнения перечислить явно.
